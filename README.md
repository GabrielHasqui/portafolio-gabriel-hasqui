# Portafolio Web | Gabriel Hasqui

Portafolio web personal de **Gabriel Leonardo Hasqui Ortega**, estudiante de
Ingenieria en Software. El sitio presenta informacion profesional, habilidades
tecnicas, proyectos destacados, un pequeno Design System y una seccion de
contacto.

El proyecto fue desarrollado con **HTML, CSS y JavaScript puro**, manteniendo una
estructura simple, facil de entender y preparada para publicarse con GitHub
Pages.

## Caracteristicas

- Diseno personal con estilo tecnico tipo terminal.
- Navegacion clara entre secciones.
- Seccion de habilidades organizada por categorias.
- Tres proyectos destacados con descripcion, problema, solucion, tecnologias e imagen.
- Design System con colores, tipografia, espaciado y componentes reutilizables.
- Formulario de contacto con validacion basica.
- Diseno responsive para computadora, tablet y telefono.
- Codigo separado en archivos de HTML, CSS y JavaScript.

## Secciones del sitio

- **Inicio:** presentacion profesional, foto de perfil y accesos principales.
- **Sobre mi:** informacion academica, perfil profesional e intereses.
- **Habilidades:** tecnologias agrupadas por Backend, Frontend, Datos, IA y herramientas.
- **Proyectos destacados:** tarjetas con proyectos relevantes y enlaces a GitHub.
- **Design System / Componentes:** paleta, tipografia, espaciados y componentes usados.
- **Contacto:** enlaces profesionales y formulario de contacto.

## Funcionalidades JavaScript

- Menu responsive para pantallas pequenas.
- Filtro de proyectos por categoria.
- Validacion basica del formulario de contacto.
- Boton para volver al inicio al hacer scroll.

## Como ejecutar el proyecto

Opcion simple:

1. Descarga o clona el repositorio.
2. Abre el archivo `index.html` en el navegador.

Opcion con servidor local:

```bash
python -m http.server 5500
```

Luego abre en el navegador:

```text
http://localhost:5500
```
