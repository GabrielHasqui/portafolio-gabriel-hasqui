## Plan de trabajo

1. Crear la estructura base del proyecto.
2. Construir el HTML semantico completo en `index.html`.
3. Crear el sistema visual en `css/styles.css` usando CSS Custom Properties.
4. Agregar responsive design con Flexbox, Grid y media queries.
5. Implementar JavaScript en `js/main.js`.
6. Probar navegacion, formulario, filtros, modal y boton de volver arriba.
7. Crear `README.md` con descripcion, tecnologias, instrucciones y capturas.
8. Subir a GitHub y publicar con GitHub Pages.

## Reglas tecnicas

- Usar HTML5 semantico: `header`, `nav`, `main`, `section`, `article`, `aside`, `figure`, `figcaption`, `footer`, `dialog`, `form`, `label`, `input`, `textarea`, `button`.
- Mantener separacion entre estructura, estilos y comportamiento.
- No usar React, Vite, Tailwind, Bootstrap ni librerias innecesarias.
- Usar CSS propio con variables en `:root`.
- Usar JavaScript propio con funciones pequenas y legibles.
- Evitar informacion personal sensible.
- Mantener nombres de clases claros y reutilizables.
- El sitio debe funcionar al abrir `index.html` directamente y tambien en GitHub Pages.

## Interactividad minima esperada

- Menu responsive.
- Filtro de proyectos por categoria.
- Modal o dialogo de detalle de proyecto.
- Validacion del formulario de contacto.
- Boton para volver al inicio.
- Resaltado de enlace activo en navegacion si se implementa sin complicar.
